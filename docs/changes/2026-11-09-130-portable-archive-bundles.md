日期：2026 年 11 月 9 日，Asia/Shanghai。类型：功能、测试、文档。插件版本：0.1.2。相关 Git 提交：尚未提交；起点为已核实的 `00d2df9`。

## 问题与目标

普通实验已有整体复制后的报告能力，但续跑链的目录身份、来源和指纹绑定原绝对路径；原报告、规则预览和对照的关联路径也可能在搬迁后失效。直接替换原 JSON 路径会破坏历史字节和摘要。

本批新增独立目录交付包，明确选择来源根、主实验或续跑入口与派生产物，只复制必要分析依赖。包换目录且原目录不可用时仍能核验、重新生成报告、浏览并定位原事件。原文件、运行身份、领取记录和历史指纹不改写；不增加搬迁后的续跑规划 / 执行或模型调用。

## 实现与技术取舍

选择目录包而非改写历史元信息。archive-manifest.json 版本1保存原逻辑根、主入口、产物及每份 payload 文件大小 / SHA-256，文件保持原相对布局。源冻结输入先核对，复制后再核验语义、精确闭包、成员和摘要，最后发布清单。输出必须新建且在所选归档目录之外。缺失、越界、错误派生来源、链接 / junction、额外成员或复制中变化均拒绝；宿主、工作区、凭据和普通进程日志不加入闭包。

规范路径作为关联条件：对照基线必须是原 evidence 旁的 case.json，候选只可改变断言；评测的 evidence、runtime 和 runDir 绑定选定样本，casePath 允许执行副本和冻结批次输入两个合法位置；报告和预览来源须属于选定实验 / 显式祖先链。保存的派生结论仍是保存值，不因此声称重新评分。实验规则预览仍限定已完成普通实验。

physical 只解析包内已列明成员和祖先目录；未列明原路径即使仍存在也不回退读取。logical_str 还原原字符串参与身份和指纹核对。未启用上下文时保持旧行为，退出或异常后恢复。浏览线程使用实例级映射，不依赖 ContextVar 在线程间继承。

报告绑定首次语义验证前取得的清单字节，在输出前再次核对文件；新报告限定在包外，仅将已知派生关联转为当前物理路径，不替换用户输入、配置或摘要载荷。原评分、原因统计和续跑分母复用。浏览器只枚举清单已有产物，JSON / Markdown 和事件定位核对实际缓冲区，轨迹分页从同一文件流计算完整摘要后才返回，保持大文件分页。普通浏览不增加全流摘要读取。

## 限制与后续

verify 的 taskEvaluationPerformed=false，仅表示文件与冻结绑定核验，不等于任务通过；fresh inspect 和断言需显式 --report。目录包用于只读分析，不恢复宿主或模型内部会话，不提供确定性重放、签名、多文件事务、fsync 或断电可靠性。共同修改清单和全部数据不在摘要保证内。当前验收限定 Windows，跨操作系统另行验证。

新报告和额外产物写在包外；浏览只在显式包根启用单包映射，不自动合并任意档案。ZIP、在线备份和搬迁后调度续跑不在本批范围。
