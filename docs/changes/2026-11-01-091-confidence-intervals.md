## 问题与目标

原报告能展示重复分布、观测均值及差值范围，但样本范围不代表参数的不确定性。增加固定 95% 的通过率与配置配对差值区间，并显式保留小样本、不可用、缺失 / 排除和统计假设边界；不改变任务断言、原描述性统计或基线回归退出码。

## 实现与技术取舍

通过率只在同用例 / 配置 / 来源的合格可评测样本上用 Wilson score 近似区间；全部通过 / 失败仍保留宽度，零样本不可用。配对通过率差用 [-1,1] 上 Hoeffding 双尾界反解，保留配对差值和不一致数，小样本可能给出完整 [-1,1]。选择保守界避免二值小样本零观察方差形成假精确，不采用独立比例相减。

数值指标先按完整配对逐个计算右减左，再按配对差值的样本方差和 n-1 自由度计算 t 区间。临界值用不完全 beta 连分式及有界二分求解，并按 df 缓存；差值缩放后计算方差，数值异常返回明确不可用。n<2、零观察方差或无法表达的边界不输出零宽 / 无限区间，已有点估计可保留。方法来源、公式和理由见 [区间说明](../uncertainty.md)。

区间筛选在原配对的 verified / matched / 同来源条件后，再要求双方 completed、录制 complete 且可评测；每个指标再排除非有限、布尔或缺失值。每个区间记录自己的 n、纳入 repeatIndices、计划数和排除原因。通过率记录本来源排除与其他来源数量，缺失不补零。原 summary、rateDifferences、metrics 描述性字段不改，不能将新区间当作旧范围点估计的区间。

仅标称 95%，n<30 是提示而非有效性判据。独立性、同分布 / 正态假设未验证，无多重比较或可选停止校正，不提供自动显著性或配置优胜结论。报告版本 1 / 2 / 3 不变，新增字段与 policy 版本 1；旧报告不补算。没有引入第三方 Python 依赖、模型运行或新 CI 工作流。
