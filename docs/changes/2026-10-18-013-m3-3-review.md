## 审查结果与技术取舍

1. **P1：同步写回工具结果会阻塞超时监督。** [runner.py](../../dsh_eval/runner.py) 在 `supervise` 主循环直接对管道执行 `stdin.write` / `flush`。文件内容没有大小限制；当返回文本超过管道容量，而适配器停止消费 stdin 时，监督循环无法继续检查任务期限或执行清理。使用合法一秒预算和 256 KiB 文本复现：专用测试进程发出工具请求后两秒不读 stdin，最终 BrokenPipeError，耗时 2.06 秒，intervention 为 null，分类为 runtime_error，丢失应有的超时事实；若进程持续不消费，写入会持续阻塞。需要让写入与超时监督独立，并添加管道不消费时仍能取消 / 超时与回收的回归检查。五秒 JavaScript 工具响应期限无法替代 Python 对失去响应适配器的监督。
2. **P2：路径过时用例误拒绝合理的发现方式。** [stale-path.case.json](../../fixtures/evaluation/stale-path.case.json) 的 tool-2 将 eval_list 参数固定为 `docs`，但任务文本只要求用 eval_list 发现当前文件，工具也明确支持根目录 `.`。README → 旧路径失败 → eval_list('.') → 读取当前文件 → 正确答案同样满足要求，却会得到 insufficient_evidence，并导致整个任务 unevaluable。已在成功轨迹的内存副本中将发现步骤和结果换成环境实际生成的根目录列表，其他五条断言全部 passed，只有 tool-2 证据不足。建议允许等价目录发现方式，或显式收紧任务并说明评测目标；优先检查发现目标文件的事实。

状态复制与按路径计数、同请求去重、协议版本和身份校验、普通工具错误与基础设施错误分开、正常注册与模型调用均符合本阶段方向。没有因上述发现否定旧样例的真实执行结果；现有测试尚未覆盖这两类边界。

P1 的最小复现（仓库根目录运行，创建的专用进程会自行在两秒后退出，不调用模型）：

```python
import json, subprocess, sys, time
from dsh_eval.environment import StatefulEnvironment
from dsh_eval.runner import supervise, _process_options

env = StatefulEnvironment({"files": {"large.txt": "x" * 262144},
                           "stateful": {"transientReadFailures": {}}}, "review")
env.bind("session")
request = {"type": "tool-request", "bridgeVersion": 1, "requestId": "request",
           "caseRunId": "review", "sessionId": "session", "operation": "read",
           "arguments": {"path": "large.txt"}}
child = subprocess.Popen(
    [sys.executable, "-u", "-c",
     "import sys,time;print(sys.argv[1],flush=True);time.sleep(2)", json.dumps(request)],
    stdin=subprocess.PIPE, stdout=subprocess.PIPE, stderr=subprocess.DEVNULL,
    text=True, encoding="utf-8", **_process_options())
report = {}
started = time.monotonic()
try:
    supervise(child, 1, environment=env, report=report)
except OSError as error:
    print(type(error).__name__)
finally:
    child.wait(timeout=5)
    for stream in (child.stdin, child.stdout):
        if not stream.closed:
            try:
                stream.close()
            except OSError:
                pass
print(round(time.monotonic() - started, 2), report)
```
