## 关键逻辑与技术取舍

保留regressionComparisonFormatVersion=1和原保存数据。目录识别任意名称的比较JSON，读取仍有8MiB单文档及目录项目数限制，不将其称作总扫描资源硬限。页面读取保存的gate / exitCode、compared / total、各类变化、原因和配置差异，过滤不重算分母或门禁。来源保存值及changedFields与比较时复验值分开展示；输入错误2不冒充正常覆盖不足2。

浏览响应新增regressionSources和按原samples一基索引的regressionEvidence，关联描述符不写回源文件。前端仅使用这些描述符中的核准ID，不从sourceResult / sourceEvidencePath等保存字符串拼接跳转。每个指针先通过配置根守卫，再读对应JSON；来源图、配置、样本键、运行身份和规范路径匹配后才提供按钮。原评测及轨迹使用同一受绑定运行，精确事件继续复用原评测页及runId / sessionId / seq定位。

普通实验直接关联原矩阵与批次；显式v1 / v2续跑按有界保存图关联，拒绝循环与断裂，不调用可能跨根加载的报告加载器、隐藏领取记录或执行锁，也不重做计划指纹。恢复检查点只有明确保存的恢复关联及规范运行位置可用时才恢复缺失身份，不以复制的ID替代来源归属。

只配置CI下载目录时，原路径即使仍存在于磁盘，只要不在允许根中也不读取或补找。缺源、跳过、身份或路径冲突只禁用对应关联，保存的比较结论仍可查看。可访问关联的结构检查不是重新评分、来源签名或多文件一致快照。

开发复查补齐了三类边界：合法终态v2结果的祖先可仍为running，浏览只在祖先允许该状态，顶层仍须终态；证据 / 原评测的runDir、runtimeReport及额外导航字段不得借旧页面二次跳到别的case，路径两端都不可用时不把None==None当作匹配；运行目录在枚举前须精确为case/traces/<runId>，再核对run.json实际身份及版本2的唯一会话 / 标准文件名，拒绝目录junction转向另一录制。该junction复现未重写计划、证据或评测JSON，只改变录制目录链接；经原路径读取的录制内容已变为另一真实run，不声称所有逻辑路径字节仍相同。
