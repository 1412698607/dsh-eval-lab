# 修改记录 146 录制资源测量复查与校验修正

日期：2026年11月17日，Asia/Shanghai。类型：修复、测试、文档。插件版本：0.1.2。相关Git提交：本记录形成时尚未提交；开发起点为已核实的 `cf2cccfb4801ed1f5228a6cc414dfec33b923ba6`。

## 问题与复查范围

复查[145](2026-11-17-145-recorder-resource-profiling.md)的测量脚本、Python对照器、状态清理优化、测试、公开逐次数据和文档。生产状态替换的成功标志、重试及失败清理未发现确认缺陷，补强三类测量 / 校验边界：

1. 时间归一化直接覆盖startedAt / updatedAt，可能把等长无效日期隐藏。现在先核对有效且符合Date.toISOString形式的时间，再做有限归一化；JS与Python分别检查，包含不存在的日历日期。
2. 对照器会静默忽略字符串、布尔值或列表等非法指标，部分缺失内存 / flush CPU还会进入不合法运算。现在明确数值容器与叶子类型，非法值拒绝，合法缺失向派生差值和比例传播null，不能补零；溢出也拒绝。
3. producer异常时只恢复fs包装，没有关闭已创建recorder，ELD也不是所有异常路径都关闭。现在先尝试close排空已接纳工作，再恢复四个fs函数，保留原始测量错误；ELD通过外层finally关闭。清理自身失败不会替换首个失败，失败样本不登记为completed。

另将详细架构中“最后清理临时文件”的旧描述改为只在rename未成功时清理；成功或重试后成功均不再unlink已移走的临时名。
