## 维护方式

采用仓库内 Markdown，与代码一起查看差异和维护。一次可独立说明的改动对应一份记录，当前状态写入进度文档，历史结果保留在批次记录中。记录编号用于文档索引，与 Git 提交号分开。

`AGENTS.md` 为在本仓库工作的后续编码助手提供持续约定。人工或其他工具修改代码时，也需要按同一约定维护文档；当前没有自动检测文档同步的 CI 检查。
