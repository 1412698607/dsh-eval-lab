# 修改记录 019 M4.2 离线配置比较报告

日期：2026 年 10 月 21 日，Asia/Shanghai。类型：功能 / 测试 / 文档。插件版本：`0.1.2`。本批相关 Git 提交：尚未提交；已核实前批 M4.1 溢出修复为 `a39e43c`、主体为 `1a6cf69`。

## 问题与目标

M4.1 已有重复样本和指标，但按请求配置分组的旧汇总不能直接作为实际模型成绩：实际路由可能不匹配，日志可能后来损坏，来源和缺失覆盖也可能不同。需要在保留原实验的前提下，核对同任务 / 初始环境和实际配置，再给出可回查的比较、分母及不确定性边界。

本批增加一个终态实验的离线报告，不重新执行任务。报告同时呈现全部计划统计与匹配配对子集，按用例和来源分开；一个配置可以报告但没有配置间差值，不从少量验收样本得出模型提升或成本结论。

## 实现与技术取舍

`--report` 读取版本 1 终态实验，从传入文件旁解析冻结输入和批次，核对展开位置、样本数、配置、批次关联及执行 / 录制身份去重。路径限制在实验和对应批次内，不能借旧绝对目录读取另一份数据；现有证据中的 Windows 原生分隔符另行兼容。输入快照完整比较任务、环境声明 / 状态化故障计数、预算、断言、版本和 caseId，taskFingerprint 排除 configRef 后计算 SHA-256。它是内容标识，不是签名或实际环境执行证明。

每项核对 evidence 身份、source、实际配置与路径，直接复用 evaluate 的真实 Node inspect、三维分类和观测指标，不再编写一份断言 / 摘要校验器。新旧字段分别保存，changedFields 解释复验差异。全局计划或批次关联冲突拒绝输入；单样本输入 / 证据冲突为 rejected / unevaluable 并保留在原分母；调度 error 无法复验为 unavailable，skipped 不补身份。verification=verified 只表示关联核对和复验处理完成，录制与任务结论另看。

配置匹配要求 evidence 全 configRef 相符、录制完整且身份一致、至少一个 request/header 且所有 provider / model 一致。unknown / mismatched 仍保留在请求组的全部计划统计，不能归入目标配置配对。来源分别展示；live / synthetic 是声明而非真实性签名，合成数据不能作为模型表现证据。

比较按用例、配置对、来源分别建立，同 repeatIndex 的两侧均 verified / matched 才入选。指标再选择双方均有值的共同配对，防止把不同覆盖子集的两个均值直接相减。差值方向固定右减左。观测数、缺失数、范围、原计划对数和排除数同时保留；有效子集求和溢出沿用 metrics 的 reason，均值与均值差保持 null。费用不补零，任务分类不受指标异常改变。

选择独立 JSON / Markdown 和逐项复验结果，便于审阅及 M5 复用；没有修改历史 experiment / evidence / evaluation 格式，也没有给旧实验补写“修复后指标”。暂不合并多个实验，避免引入跨实验任务集合和权重对齐；不计算置信区间或显著性，报告样本量、覆盖、观测范围、固定顺序与选择偏差限制。范围不是置信区间，没有自动赢家。

所有输入核对和复验先于新输出目录创建；随后排他写入新 UUID 目录。磁盘失败可能留下本次不完整目录，旧结果不覆写；没有原子发布、fsync、续写或在线一致快照。报告成功退出 0 表示报告生成，样本 failed / unevaluable 不改变该退出码；输入输出错误为 2。原任务入口的 0 / 1 / 2 不变。

独立命令行复验还发现 Windows 重定向时 stdout 使用系统代码页，按 UTF-8 读取中文报告失败；同轮在既有 CLI 测试中强制 PYTHONIOENCODING=cp936，先复现 UnicodeDecodeError，再为模块入口固定 stdout UTF-8。文件编码和 JSON 内容不变，原评测 / 执行入口的模块 stdout 同样统一；直接调用 main 的内存流不重配置。Markdown 时间按 Asia/Shanghai 显示，浮点数显示六位有效数字，完整数值仍存 JSON，不用显示值重新统计。

## 风险与后续

现有 source、profile 和运行事实仍由适配器声明，不是签名；输入与记录被同时改写也不在摘要检测保证内。全部计划组与条件匹配子集不能混用，覆盖不足可能造成选择偏差；运行耗时不是纯模型延迟。需要从稳定终态目录报告，不提供在线一致快照。

当前仅支持单实验；没有跨实验合并、统计推断、结果浏览或 CI。下一批 M5 先浏览已有用例 / 实验 / 报告及逐样本三维结论，再加入无模型确定性 CI；真实模型任务另设触发与预算。主路线剩一个实施批次。未自动提交或推送。

## 面试讨论点

可以沿 `--report → 冻结输入与批次关联 → fresh evaluate / Node inspect → 请求路由核对 → 同来源配对 → 共同指标子集 → 新报告` 演示。重点讨论请求配置与实际配置、全部计划分母与条件子集、缺失与零、指标溢出与任务结果独立、旧成功不能覆盖损坏日志，以及描述性范围为何不能称为置信区间。真实与合成验证应分别陈述。
