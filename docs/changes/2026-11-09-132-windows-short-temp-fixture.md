## 问题与目标

归档提交首次云端Python测试失败，公开注释仅有退出码1，旧日志尚未核对，见[131](2026-11-09-131-archive-ci-and-capability-matrix.md)。在独立环境复核中，实际复现一个确定的测试夹具缺陷：TMP / TEMP 使用同一NTFS目录的8.3短路径别名时，夹具保存未规范化根，而 ArchivePaths 保存规范化根，导致本应相同的包内路径比较失败。

未修正时，真实短路径子进程复现4项失败、2项错误。该现象证明夹具缺陷存在，不能在缺少旧CI日志时断言它是旧失败的唯一原因。保留原CI失败，使用修正后的新提交独立验证。
