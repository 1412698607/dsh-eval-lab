## 最短复现入口

在项目根目录，需要 Python3.12+、Node.js22.8+：

```powershell
# 生成、独立复验并退出，不调用模型：
npm.cmd run demo:workflow -- --generate-only
# 或生成后启动只读浏览，打开完整URL，Ctrl+C停止：
npm.cmd run demo:workflow
# 本地无模型回归：
npm.cmd run check
npm.cmd test
npm.cmd run test:python
```

已有稳定归档可用 `python -m dsh_eval --report <结果JSON>` 重新检查；目录包先 `python -m dsh_eval.archive_bundle verify <包目录>`，再 `python -m dsh_eval --report <包目录>/archive-manifest.json`。缺少或越界的依赖不从其他位置补找，具体输出位置与参数见对应说明。

真实执行入口与离线入口分开：`--experiment … --run`、`--case … --run`及续跑执行会使用配置的模型；上述演示、检查、报告、规则对照和包核验不新增模型任务。真实宿主组件检查另有安装与版本前置条件，不是合成演示的依赖。

## 保留的边界

record 成功只表示入队，flush / sealed没有fsync或断电保证；摘要不是签名，不覆盖清单与数据共同改写。目录包不替代完整宿主备份，不恢复模型会话或确定性重放。浏览和多文件复制不提供在线一致快照或多文件事务。

token调度阈值只在任务结束后停止后续安排，缺失用量不补零；任务内token / 步骤 / 费用硬限额、多任务并发调度、未知任务自动重试、任意跨实验合并、日志轮转与跨平台覆盖均不作为当前已完成能力。待写文本队列上限不是进程总内存硬限额。更多模型、任务和重复需要另定范围，不能仅凭现有小样本或通过用例作泛化结论。
