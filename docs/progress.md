# dsh-eval-lab 开发进度

截至 2026 年 10 月 11 日，项目版本为 `0.1.1`，已完成实时会话轨迹记录器及 M2.1 输出与配置。18 项功能测试、真实 Harness 会话组件接入及两种真实子进程输出检查通过。M2.2 状态与离线检查、M2.3 真实模型联调，以及后续自动评测仍待实现。

## 项目目标

围绕 DeepSeek Harness 构建 Agent 行为回归测试工具：对固定任务与环境运行 Agent，检查工具行为和最终结果，比较不同配置的稳定性、调用数量与资源消耗。作品集重点是插件扩展、事件记录、测试环境和评测方法。

## 已知限制

- 仅录制新增事件，没有补齐插件加载前、恢复会话或 fork 继承的历史，日志不能直接用于完整会话恢复。
- `runId` 表示一次记录器启动批次，尚未定义为一次评测的编号。
- `flush()` 等待异步文件追加完成，没有执行 fsync；强制退出和断电可能导致数据丢失。
- 失败状态只保存在当前进程，没有持久化完成标记，离线读取不能仅凭文件存在就确认日志完整。
- 没有队列容量控制、日志轮转或会话状态淘汰。高负载和长时间运行能力尚未验证。
- 哈希文件名避免路径解释问题，但没有加密事件内容。
- Cordis 4.0.4 卸载时捕获清理错误；不能仅凭 `fiber.dispose()` 完成判断日志有效。持久化状态和离线检查仍待 M2.2 实现。
- 插件诊断的输出边界已验证；SDK 和 headless 整体协议、任务驱动及退出链路尚未联调，桌面安装也未验证。
- 没有性能基准、真实模型成功率或费用改善数据。
